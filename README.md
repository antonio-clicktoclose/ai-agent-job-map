# AI Agent Job Map

137 jobs AI agents can do inside a business, mapped by department into drop-in
Claude Code skill files. This is an original starter map built by ClickToClose,
not copied from any competitor product.

Drop any skill file into your Claude Code projects directory and Claude can run
that job. Each skill is self-contained: instructions, inputs, and the output
contract lived in one file.

## Why a map instead of a grab bag

Most teams bolt AI on at random, one prompt at a time. That is why so many AI
projects stall. A map gives you the order to build in. It shows every job across
the seven departments a company already runs, so you can see what is connected
before you spend a dollar.

## The seven departments

| Department | What it owns |
|---|---|
| Sales | targeting, outreach, sequencing |
| Deals | replies, calls, closing, pipeline |
| Marketing | content, brand, distribution |
| Operations | onboarding, builds, client ops |
| Intelligence | companies, people, markets |
| Customer | support, success, community |
| Back Office | money in, books, office, people |

## How to use it

1. Pick the department you want to upgrade this quarter.
2. Read that folder's README for the order.
3. Drop the skill files you need into your Claude Code skills directory.
4. Point Claude at the real data it should read. Every skill is generic until it
   is bound to your business.

## The starting principle: one company brain

Before you spin up any agent, load everything your business knows into a shared
place Claude can read. Every job after that stops guessing. The map is organized
around that idea: a shared brain first, then agents that read it.
